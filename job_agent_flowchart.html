Parallel thread listening to terminal keys like [S]kip, [Q]uit, or [P]rint status in real-time.

SQLite Table: applications

Tracks the state of all parsed, skipped, and completed applications.

applications Main Ledger DB
Field Name Type Constraints Description / Purpose
id INTEGER PRIMARY KEY AUTOINCREMENT Unique internal identifier for the application record.
job_title TEXT - Name of the role scraped from the platform card.
company TEXT - Name of the employer company.
platform TEXT - Job portal source ('linkedin' or 'naukri').
apply_url TEXT UNIQUE The unique link to the job post. Prevents processing duplicates.
apply_type TEXT DEFAULT 'easy_apply' Indicates submission method ('easy_apply' or 'external').
match_score INTEGER - Matching rating returned by LLM Scorer (0-100).
status TEXT DEFAULT 'pending' Current state ('pending', 'applied', 'skipped', 'failed', 'manual_apply').
resume_path TEXT - Local file path to the customized tailored resume document.
applied_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP Datetime record of creation or last update.
outreach_sent BOOLEAN DEFAULT 0 Boolean flag showing whether LinkedIn recruiter message succeeded.
notes TEXT - Pipeline execution logs, errors, or LLM evaluation reasoning.
SQLite Table: outreach_log

Logs specific recruiter contact notes dispatched by the outreach agent.

outreach_log Outreach Tracking
Field Name Type Constraints Description / Purpose
id INTEGER PRIMARY KEY AUTOINCREMENT Unique outreach transaction row id.
application_id INTEGER FOREIGN KEY -> applications(id) References the parent job application database entry.
recruiter_name TEXT - Name of the recruiter targeted on LinkedIn.
company TEXT - Employer company associated with the recruiter.
message_text TEXT - The custom generated message sent within the connection invite.
sent_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP Date and time the invite was dispatched.
Auto-fill Form Memory Cache

Fuzzy matches form labels to pre-seeded properties or profile_qa.yaml mappings to speed up inputs.

phone / mobile Pre-mapped telephone fields to settings.phone values.
expected ctc / expected salary Fills out portal salary expectation fields based on configuration.
notice period Populates job switch availability (e.g., immediate, 30 days).
are you authorized to work Handles standard yes/no legal visa answers.
degree / highest qualification Automatically inputs college graduation qualifications.
willing to relocate / relocation Fills geographic flexibility options as defined by settings.
